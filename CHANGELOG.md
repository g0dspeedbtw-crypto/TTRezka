# Changelog — TikCut Studio

Все заметные изменения проекта **TikCut Studio** фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация версий — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.1] — 2026-11-22 (1-Click Silent Updates)

### ⚡ Максимально простое обновление в 1 клик
- **Тихий установщик без «Далее → Далее → Готово»**: на Windows включён режим `oneClick: true` и тихий перезапуск `quitAndInstall(true, true)` — приложение само закрывается, обновляется за 3 секунды и сразу открывается на новой версии.
- **Никаких лишних окон и баннеров**: обновление незаметно скачивается в фоне прямо внутри кнопки сверху (`Обновление 45%`), а когда готово — кнопка загорается зелёным **`⚡ Обновить до vX.Y.Z`**. Один клик — и всё обновлено.

## [1.2.2] — 2026-11-22

### 🛠 Исправления (Windows RTX CUDA)
- **Исправлена ошибка `cublas64_12.dll` на Windows RTX 4060 Ti**: в Windows-сборку теперь вшиваются официальные библиотеки `nvidia-cublas-cu12` и `nvidia-cudnn-cu12` с автоматической регистрацией DLL при запуске (`server_entry.py`), поэтому CUDA FP16 работает сразу из коробки без ручной установки CUDA Toolkit.
- **Проверка DLL + автоматический резерв на CPU**: перед включением CUDA проверяется доступность `cublas64_12.dll`, а при любой ошибке CUDA во время распознавания Whisper бесшовно переключается на `CPU int8` без падения обработки.

## [1.2.1] — 2026-11-22

### 🧠 Улучшение поиска топовых и смешных моментов
- **Алгоритм «Завязка → Пик → Реакция» (Peak-Anchored Windows)**: окна клипов теперь строятся вокруг реальных пиков смеха, громких эмоций, пиков карты пересмотров YouTube и взрывов чата Twitch (захватывая ~15 сек контекста до кульминации и ~12 сек реакции после).
- **Детектор смеха и резкого контраста**: вместо плоского среднего по громкости оценивается резкий скачок энергии и модуляция голоса/смеха.
- **Словарь русского юмора, стримерского сленга и реакций**: добавлена оценка смеха, реакций, шока, рейдж- и клатч-моментов с новым тегом `😂 Смешной / Реакция`.
- **Фильтр рекламы и скучных интро/аутро**: рекламные интеграции («промокод», «ссылка в описании», «спонсор») и приветствия/прощания теперь штрафуются и не попадают в топ нарезок.

### 🎤 Улучшение распознавания русской речи
- **Очистка и нормализация голоса перед Whisper**: FFmpeg-фильтр (`highpass`/`lowpass`/`dynaudnorm`) убирает низкочастотный гул и взрывы игр, выравнивая тихую речь.
- **Русский `initial_prompt` + защита от галлюцинаций**: отключено зацикливание (`condition_on_previous_text=False`, `repetition_penalty=1.1`), отфильтровываются мусорные титры Whisper вроде «Субтитры сделал DimaTorzok» и склеивается оторванная пунктуация.

## [1.2.0] — 2026-11-22 (RTX GPU Edition)

### ⚡ Оптимизация под NVIDIA RTX 4060 Ti (и все карты RTX)
- **Автоопределение видеокарты и ускорения** (`backend/hardware.py`) — в шапке приложения отображается активный движок (например, `🟢 NVIDIA GeForce RTX 4060 Ti • CUDA + NVENC` на Windows или `🍎 Apple Silicon • VideoToolbox` на macOS).
- **Whisper CUDA FP16 + модель `large-v3-turbo`** — автоматический запуск `faster-whisper` на ядрах Tensor Cores (`device="cuda", compute_type="float16"`, `beam_size=5`) в 10–25× быстрее CPU с автоматическим переходом на `CPU int8` при отсутствии CUDA.
- **Аппаратный рендер NVIDIA NVENC HQ (`h264_nvenc`)** — профиль `p5 + tune hq + VBR CQ 19` для Ada Lovelace (RTX 40-й серии), рендер клипа 9:16 за пару секунд.
- **Параллельный мульти-рендер на GPU** — одновременный рендеринг 2 клипов в параллельных NVENC-потоках на картах NVIDIA RTX.
- **⚡ Экспорт 60 FPS** — плавные 60 кадров/с для игровых стримов (CS2, Valorant, Dota 2, GTA и др.).
- **🎨 Сочность и резкость кадра (Color Pop)** — деликатное улучшение контрастности, насыщенности и резкости под ленту TikTok/Shorts.
- **🧠 Интеграция с локальным Ollama LLM на RTX GPU** — если на ПК запущен Ollama (`qwen2.5`, `llama3.1`, `gemma2`), приложение автоматически находит модели и позволяет усилить отбор смешных/виральных моментов и генерацию заголовков-хуков локальной нейросетью.

## [1.1.0] — 2026-11-22

### ✨ Новое
- **🤖 AI Face Tracking для 9:16** — локальное определение лица спикера через OpenCV и автоматическое выравнивание кадра 9:16 по лицу.
- **🎮 Режим Split-Screen для стримов (Вебка сверху + Игра снизу)** — выбор угла веб-камеры стримера и размера области; сверху крупно эмоции стримера (`1080×720`), снизу геймплей (`1080×1200`).
- **💬 Анализ пиков чата Twitch (Chat Replay)** — для записей стримов на Twitch без скачивания видео автоматически находятся моменты взрыва чата (`KEKW`, `LUL`, `АХАХА`, `ШОК`) с тегом `💬 Взрыв чата Twitch`.
- **✏️ Редактор клипа (субтитры, обрезка и заголовок-хук)** — правка текста субтитров (исправление ников, сленга, опечаток), подстройка границ начала/конца клипа и мгновенный перерендер за пару секунд.
- **🏷 Заголовок-хук (Hook Banner) + Водяной знак канала (`@ник`)** — яркая верхняя плашка на первые 4 секунды клипа и полупрозрачный водяной знак с живым предпросмотром на макете телефона.
- **✂️ Авто Jump-Cuts (Retention Boost)** — автоматическое вырезание длинных пауз (`> 0.85 сек`) с пересчётом таймкодов субтитров.
- **🎵 Фоновая музыка с авто-приглушением (Sidechain Ducking)** — загрузка своих MP3/WAV треков; музыка автоматически приглушается во время речи.
- **📦 Пакетный экспорт `.zip` + готовые описания и хэштеги** — скачивание всех клипов одним архивом вместе с `captions_and_hashtags.txt` и кнопка копирования описания на каждой карточке.

## [1.0.0] — 2026-11-22

### ✨ Новое
- **Десктопное приложение для macOS и Windows (Electron + автономный Python-движок)**:
  - Нативное окно приложения с собственной иконкой и мгновенным экраном загрузки.
  - Автономная сборка бэкенда через PyInstaller (`.app` / `.dmg` для macOS и NSIS `.exe` + Portable для Windows).
- **Анализ YouTube-видео и прошлых стримов по ссылке без скачивания всего видео**:
  - Поддержка YouTube, YouTube Live VOD, Twitch VOD, VK Video и других платформ через `yt-dlp`.
  - Чтение тепловой карты пересмотров YouTube (*Most Replayed*) и лёгких субтитров без загрузки многогигабайтных записей.
  - Точечная вырезка только выбранных 20–55-секундных фрагментов.
- **100% локальный поиск интересных моментов (без API-ключей)**:
  - Комбинированная оценка виральности (`0–100`) по пикам громкости/эмоций, динамике речи, русским виральным хукам, сменам сцен и карте пересмотров.
  - Автоматические заголовки и теги моментов (`📈 Пик пересмотров`, `🔥 Пик эмоций`, `💬 Сильный хук`, `🎤 Живая подача`).
- **Авто-субтитры на русском с караоке-подсветкой каждого слова**:
  - Локальное распознавание речи через `faster-whisper` (`tiny`, `base`, `small`, `medium`) с точными пословными таймкодами.
  - **5 стилей TikTok-субтитров**: `Hormozi Gold`, `Neon Cyber`, `Viral Green Pill`, `Fire Punch`, `Minimal Clean`.
  - **5 встроенных кириллических шрифтов**: `Montserrat Black`, `Rubik Black`, `Oswald Bold`, `Unbounded Black`, `Impact Classic`.
  - Живой 9:16 предпросмотр на макете телефона и мгновенный перерендер стиля на готовом клипе без повторного распознавания речи.
- **Форматирование видео в 9:16 (HD 1080×1920)**:
  - Два режима кадрирования: **Заполнение (Crop 9:16)** и **Размытый фон (весь кадр)** для стримов/подкастов/игр.
  - Аппаратное ускорение рендера (`h264_videotoolbox` на Apple Silicon) с автоматическим резервом `libx264`.
- **Обновления по воздуху (OTA)**:
  - Интеграция `electron-updater` с GitHub Releases (`g0dspeedbtw-crypto/TTRezka`).
  - Автоматическая проверка обновлений при запуске, ручная проверка кнопкой **«🔄 Обновления»**, прогресс-бар скачивания и установка в один клик.
- **Встроенный просмотр ченджлога («📋 Что нового»)** прямо внутри интерфейса приложения.

### 🛠 Исправления и CI/CD
- Настроен GitHub Actions workflow (`.github/workflows/build-desktop.yml`) для автоматической сборки macOS (`.dmg`, `.zip`) и Windows (`.exe`) и публикации OTA-релизов по тегам `v*`.
- Добавлен флаг `--publish never` для веточных сборок и независимая матрица `fail-fast: false`.
