## [1.1.0] — 2026-11-22

### ✨ Новое
- **🤖 AI Face Tracking для 9:16** — локальное определение лица спикера через OpenCV и автоматическое выравнивание кадра 9:16 по лицу.
- **🎮 Режим Split-Screen для стримов (Вебка сверху + Игра снизу)** — выбор угла веб-камеры стримера и размера области; сверху крупно эмоции стримера (`1080×720`), снизу геймплей (`1080×1200`).
- **💬 Анализ пиков чата Twitch (Chat Replay)** — для записей стримов на Twitch без скачивания видео автоматически находятся моменты взрыва чата (`KEKW`, `LUL`, `АХАХА`, `ШОК`) с тегом `💬 Взрыв чата Twitch`.
- **✏️ Редактор клипа (субтитры, обрезка и заголовок-хук)** — правка текста субтитров (исправление ников, сленга, опечаток), подстройка границ начала/конца клипа и мгновенный перерендер за пару секунд.
- **🏷 Заголовок-хук (Hook Banner) + Водяной знак канала (`@ник`)** — яркая верхняя плашка на первые 4 секунды клипа и полупрозрачный водяной знак с живым предпросмотром на макете телефона.
- **✂️ Авто Jump-Cuts (Retention Boost)** — автоматическое вырезание длинных пауз (`> 0.85 сек`) с пересчётом таймкодов субтитров.
- **🎵 Фоновая музыка с авто-приглушением (Sidechain Ducking)** — загрузка своих MP3/WAV треков; музыка автоматически приглушается во время речи.
- **📦 Пакетный экспорт `.zip` + готовые описания и хэштеги** — скачивание всех клипов одним архивом вместе с `captions_and_hashtags.txt` и кнопка копирования описания на каждой карточке.

## [1.0.0] — 2026-11-22

### ✨ Новое
- **Десктопное приложение для macOS и Windows (Electron + автономный Python-движок)**:
  - Нативное окно приложения с собственной иконкой и мгновенным экраном загрузки.
  - Автономная сборка бэкенда через PyInstaller (`.app` / `.dmg` для macOS и NSIS `.exe` + Portable для Windows).
- **Анализ YouTube-видео и прошлых стримов по ссылке без скачивания всего видео**:
  - Поддержка YouTube, YouTube Live VOD, Twitch VOD, VK Video и других платформ через `yt-dlp`.
  - Чтение тепловой карты пересмотров YouTube (*Most Replayed*) и лёгких субтитров без загрузки многогигабайтных записей.
  - Точечная вырезка только выбранных 20–55-секундных фрагментов.
- **100% локальный поиск интересных моментов (без API-ключей)**:
  - Комбинированная оценка виральности (`0–100`) по пикам громкости/эмоций, динамике речи, русским виральным хукам, сменам сцен и карте пересмотров.
  - Автоматические заголовки и теги моментов (`📈 Пик пересмотров`, `🔥 Пик эмоций`, `💬 Сильный хук`, `🎤 Живая подача`).
- **Авто-субтитры на русском с караоке-подсветкой каждого слова**:
  - Локальное распознавание речи через `faster-whisper` (`tiny`, `base`, `small`, `medium`) с точными пословными таймкодами.
  - **5 стилей TikTok-субтитров**: `Hormozi Gold`, `Neon Cyber`, `Viral Green Pill`, `Fire Punch`, `Minimal Clean`.
  - **5 встроенных кириллических шрифтов**: `Montserrat Black`, `Rubik Black`, `Oswald Bold`, `Unbounded Black`, `Impact Classic`.
  - Живой 9:16 предпросмотр на макете телефона и мгновенный перерендер стиля на готовом клипе без повторного распознавания речи.
- **Форматирование видео в 9:16 (HD 1080×1920)**:
  - Два режима кадрирования: **Заполнение (Crop 9:16)** и **Размытый фон (весь кадр)** для стримов/подкастов/игр.
  - Аппаратное ускорение рендера (`h264_videotoolbox` на Apple Silicon) с автоматическим резервом `libx264`.
- **Обновления по воздуху (OTA)**:
  - Интеграция `electron-updater` с GitHub Releases (`g0dspeedbtw-crypto/TTRezka`).
  - Автоматическая проверка обновлений при запуске, ручная проверка кнопкой **«🔄 Обновления»**, прогресс-бар скачивания и установка в один клик.
- **Встроенный просмотр ченджлога («📋 Что нового»)** прямо внутри интерфейса приложения.

### 🛠 Исправления и CI/CD
- Настроен GitHub Actions workflow (`.github/workflows/build-desktop.yml`) для автоматической сборки macOS (`.dmg`, `.zip`) и Windows (`.exe`) и публикации OTA-релизов по тегам `v*`.
- Добавлен флаг `--publish never` для веточных сборок и независимая матрица `fail-fast: false`.
- Обновлён macOS-раннер CI на `macos-latest`.
